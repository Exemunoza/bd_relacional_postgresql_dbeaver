# Estructura DDL

Este archivo contiene los scripts de definición de tablas relacionales utilizando lenguaje de definición de datos (DDL) en PostgreSQL. Se incluyen las tablas `clientes`, `pedidos` y `empleados`, con sus respectivas claves primarias y relaciones mediante claves foráneas.

## Objetivo

Establecer la estructura base de la base de datos para una tienda en línea, permitiendo la gestión de clientes, pedidos y empleados.

## Ejecución

1. Abrir DBeaver y conectar a la base de datos PostgreSQL.
2. Ejecutar el script `clientes_pedidos.sql` en el editor SQL.
3. Verificar la creación de las tablas y sus relaciones.
