# Modelo de Datos

Este archivo contiene el diagrama entidad-relación (ER) que representa el modelo lógico de la base de datos antes de su implementación.

## Objetivo

Visualizar las entidades, atributos y relaciones que conforman el sistema de gestión de pedidos, clientes, productos y empleados.

## Contenido

- `diagrama_ER.png`: imagen del diagrama ER generado desde DBeaver.

## Recomendación

Revisar el diagrama antes de ejecutar los scripts SQL para comprender la estructura y relaciones del modelo.
