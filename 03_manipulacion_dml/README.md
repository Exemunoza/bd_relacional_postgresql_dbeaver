# Manipulación de Datos (DML)

Este archivo contiene instrucciones para insertar, actualizar y eliminar datos en las tablas de la base de datos, utilizando lenguaje de manipulación de datos (DML).

## Objetivo

Simular operaciones reales sobre la base de datos, como registrar nuevos clientes, modificar direcciones y eliminar pedidos no procesados.

## Ejecución

1. Abrir DBeaver y conectar a la base de datos PostgreSQL.
2. Ejecutar el script `insert_update_delete.sql` en el editor SQL.
3. Verificar los cambios realizados en las tablas mediante consultas de verificación.
