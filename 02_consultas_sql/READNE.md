# Consultas SQL

Este archivo contiene consultas escritas en Lenguaje Estructurado de Consultas (SQL) para obtener información específica desde las tablas creadas. Se utilizan cláusulas como `SELECT`, `JOIN`, `WHERE` y `GROUP BY`.

## Objetivo

Extraer datos relevantes para la toma de decisiones, como pedidos realizados por clientes y resumen de compras por cliente.

## Ejecución

1. Abrir DBeaver y conectar a la base de datos PostgreSQL.
2. Ejecutar el script `consultas_select.sql` en el editor SQL.
3. Analizar los resultados obtenidos en la consola de resultados.
