# Proyecto: Base de Datos Relacional en PostgreSQL

Este repositorio contiene la implementación de una base de datos relacional para una tienda en línea, desarrollada en PostgreSQL y gestionada mediante DBeaver. Se abordan los requerimientos funcionales mínimos esperados, incluyendo definición de estructuras, consultas SQL, manipulación de datos y modelado.

## Estructura del repositorio

- `01_estructura_ddl/`: scripts de creación de tablas.
- `02_consultas_sql/`: consultas SELECT, JOIN, GROUP BY.
- `03_manipulacion_dml/`: scripts INSERT, UPDATE, DELETE.
- `04_modelo_datos/`: diagrama ER del modelo lógico.

## Herramientas utilizadas

- PostgreSQL
- DBeaver
